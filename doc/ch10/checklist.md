# 上下文状态展示与窗口保护 Checklist

> 每项以实际运行或可观察界面行为判定；开发完成后记录命令、实际结果与通过状态。

## 外置状态

- [ ] 触发单项或合计工具结果外置后，聊天区显示一条普通字重状态，内容包含“已外置”、结果数量、“到磁盘”和该次实际释放的字符数。（验证：构造超过阈值的工具结果，比较外置前后历史字符数与状态文本。）
- [ ] 未触发外置的普通工具结果不产生外置状态行。（验证：发送小工具结果，观察聊天区没有 ContextActivity 外置文本。）
- [ ] ContextActivity 的标记和正文均不含 `bold` 样式；工具调用和普通回复仍保持原样。（验证：检查渲染样式并运行既有 TUI 工具行测试。）

## 压缩状态

- [ ] 自动或紧急摘要在向摘要模型发请求前显示“正在压缩上下文…”。（验证：使用可控 Provider 暂停摘要响应，观察开始状态已进入事件流和聊天区。）
- [ ] 摘要成功后显示“已压缩上下文 · Before → After 估算 Token”，两个数来自该次压缩前后的同一预算估算。（验证：构造长历史，记录 ContextResult 统计与界面文本并比对。）
- [ ] 未达到阈值、没有较早历史或自动熔断时，不显示“正在压缩上下文”。（验证：分别构造三种场景并检查上下文状态行。）

## 自动静默与手动反馈

- [ ] 使用 `context.window_tokens: 13001` 发送首条普通消息时，自动检查不生成摘要请求，也不显示“没有可压缩的较早历史”。（验证：记录测试 Provider 请求；应只有正常模型请求，且聊天区无 ContextActivity。）
- [ ] 在没有较早历史的会话输入 `/compact` 时，不发送普通 Agent 请求，显示非加粗的“没有可压缩的较早历史”，并恢复输入框。（验证：通过 TUI 输入命令，检查会话、请求记录、状态行和输入状态。）
- [ ] 小窗口配置仍可用于实际压缩测试；当出现较早历史且达到阈值时，仍会生成摘要并显示开始与完成状态。（验证：用 13001 配置准备可压缩历史，观察摘要请求和两条状态。）

## 集成与回归

- [ ] Agent 按外置、压缩开始、压缩完成的顺序转发 ContextUpdated，紧急压缩成功后仍只重试原请求一次。（验证：运行 Agent 测试并检查事件与 Provider 请求顺序。）
- [ ] 原有工具调用、权限确认、流式回复、取消和 `/compact` 命令测试全部通过。（验证：运行 `pytest tests/test_agent.py tests/test_tui.py -q`。）
- [ ] 全部测试套件通过。（验证：运行 `pytest -ra`，期望没有失败；记录既有跳过项。）

## 端到端场景

- [ ] 在终端以 `window_tokens: 13001` 启动 YuCode，输入首条普通任务。（验证：正常出现模型请求和回复；没有上下文跳过或压缩状态。）
- [ ] 在同一会话中触发大工具结果或摘要压缩。（验证：依次观察非加粗的外置状态，或“正在压缩上下文…”与“已压缩上下文 · Before → After 估算 Token”；后续任务可正常继续。）
