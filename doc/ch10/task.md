# 上下文状态展示与窗口保护 Tasks

## 文件清单

| 操作 | 文件 | 职责 |
|---|---|---|
| 修改 | `src/yucode/context.py` | 上下文进度事件、字符与 Token 统计、自动静默 |
| 修改 | `src/yucode/agent.py` | 消费并转发异步上下文事件流 |
| 修改 | `src/yucode/tui/app.py` | 状态文本渲染、自动跳过过滤 |
| 修改 | `src/yucode/tui/widgets.py` | 非加粗上下文状态样式 |
| 修改 | `tests/test_context.py` | 统计、顺序、小窗口静默测试 |
| 修改 | `tests/test_agent.py` | 事件流与紧急重试回归 |
| 修改 | `tests/test_tui.py` | 状态文本、样式和 `/compact` 测试 |

## T1: 把上下文处理改为可报告进度的事件流

**文件：** `src/yucode/context.py`、`tests/test_context.py`

**依赖：** 无

**步骤：**

1. 扩展上下文结果，携带外置释放字符数和压缩前后估算 Token。
2. 将自动、手动、紧急处理及内部压缩改为按进度产生异步事件。
3. 外置完成时计算同一历史前后的字符差；真正开始摘要前产生压缩开始事件，摘要提交后产生完成事件。
4. 自动检查无较早历史时不产生事件且不请求摘要；手动无历史仍产生跳过事件。
5. 添加外置量、压缩事件顺序、压缩前后 Token、手动跳过和 13001 小窗口静默测试。

**验证：** 运行 `pytest tests/test_context.py -q`，期望全部通过。

## T2: 接入 Agent 的上下文事件流

**文件：** `src/yucode/agent.py`、`tests/test_agent.py`

**依赖：** T1

**步骤：**

1. 将请求前、手动和紧急压缩调用改为消费全部上下文进度事件。
2. 保持 Agent 对 TUI 的 `ContextUpdated` 事件接口不变，并按原有顺序转发。
3. 仅当紧急压缩的最终结果成功时重试原请求，保留一次重试上限。
4. 测试摘要开始事件在摘要 Provider 请求之前可观察，及既有 `prompt_too_long` 恢复流程仍通过。

**验证：** 运行 `pytest tests/test_agent.py -q`，期望全部通过。

## T3: 渲染非加粗的紧凑状态行

**文件：** `src/yucode/tui/app.py`、`src/yucode/tui/widgets.py`、`tests/test_tui.py`

**依赖：** T2

**步骤：**

1. 根据上下文状态与统计字段生成中文单行文本：外置、压缩开始、压缩完成、手动跳过与失败。
2. 过滤自动 `unchanged`，仅让手动跳过显示在聊天区。
3. 移除 ContextActivity 标记与正文的 `bold` 样式，不修改工具和普通消息组件。
4. 测试外置/压缩文本包含真实统计、自动小窗口首轮无状态、手动跳过仍可见，以及渲染样式无粗体。

**验证：** 运行 `pytest tests/test_tui.py -q`，期望全部通过。

## T4: 全量回归与终端交互验收

**文件：** 无新增文件

**依赖：** T1、T2、T3

**步骤：**

1. 运行上下文、Agent、TUI 的针对性测试，并修复回归。
2. 运行完整测试套件。
3. 在可用终端交互环境中，以 `window_tokens: 13001` 输入首条普通消息，观察没有上下文状态；再触发外置或压缩，观察紧凑非加粗状态和统计。
4. 记录命令、结果与无法执行的环境限制。

**验证：** 运行 `pytest -ra`，期望全部测试通过；终端场景观察与规格一致。

## 执行顺序
