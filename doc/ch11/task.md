# 工具结果截断移除 Tasks

## 文件清单

| 操作 | 文件 | 职责 |
|---|---|---|
| 修改 | `src/yucode/tools/filesystem.py` | 移除读取、查找、搜索的 12K 文本截断 |

## T1: 移除文件系统工具的文本结果截断

**文件：** `src/yucode/tools/filesystem.py`、`tests/test_tools.py`

**依赖：** 无

**步骤：**

1. 删除 12K 结果字符常量与通用文本裁剪辅助函数。
2. 读取文件直接返回完整解码文本；查找文件和搜索代码直接返回在 `MAX_MATCHES` 范围内收集的完整列表。
3. 更新摘要文字，只在 200 条数量限制命中时显示受限提示。
4. 增加大于 12K、小于 1MiB 的读取、搜索和查找结果完整性测试。
5. 回归超过 1MiB、二进制文件、无效路径和 200 条限制测试。

**验证：** 运行 `pytest tests/test_tools.py -q`，期望全部通过。

## T2: 移除命令输出的文本结果截断

**文件：** `src/yucode/tools/command.py`、`tests/test_tools.py`

**依赖：** 无

**步骤：**

1. 删除命令工具对共享 12K 常量的依赖。
2. 保留完整 stdout/stderr 合并输出，不再切片或附加“输出已截断”摘要。
3. 增加超过 12K 的成功与非零退出命令测试。
4. 回归命令超时、取消、启动失败和权限语义测试。

**验证：** 运行 `pytest tests/test_tools.py -q`，期望全部通过。

## T3: 验证完整内置结果会被上下文外置

**文件：** `tests/test_agent.py`、`tests/test_context.py`

**依赖：** T1、T2

**步骤：**

1. 使用内置读取文件工具构造大于 50K、小于 1MiB 的真实文本结果。
2. 驱动 Agent 进入下一轮模型请求，检查 ContextManager 在请求前外置该结果。
3. 验证缓存文件逐字保存原始完整内容，Provider 历史只包含路径、预览和重新读取提示。
4. 验证未达到 50K 的完整结果仍按原文留在历史中。

**验证：** 运行 `pytest tests/test_agent.py tests/test_context.py -q`，期望全部通过。

## T4: 全量回归与终端验收

**文件：** 无新增文件

**依赖：** T1、T2、T3

**步骤：**

1. 运行工具、上下文、Agent 和 TUI 的针对性测试，修复回归。
2. 运行完整测试套件。
3. 在可用终端交互环境中读取一个大于 50K、小于 1MiB 的文本文件，然后继续普通任务。
4. 观察工具行不再提示截断，下一次模型请求前出现外置状态，缓存文件可重新读取。
5. 记录命令、实际结果与环境限制。

**验证：** 运行 `pytest -ra`，期望没有失败；终端场景符合规格。
