# 工具结果截断移除 Checklist

> 每项以实际运行或可观察行为判定；开发完成后记录命令、实际结果与通过状态。

## 完整工具结果

- [x] 读取大于 12K、小于 1MiB 的文本文件时，工具结果包含完整文件原文，摘要不出现“内容已截断”。（验证：创建并读取约 60K 字符文本，比较工具结果与文件内容。）
- [x] 在不超过 200 条限制时，文件查找返回所有已收集路径，代码搜索返回所有已收集匹配，摘要不出现文本截断提示。（验证：构造长路径和长匹配行，比较结果数量与完整内容。）
- [x] 成功和非零退出的命令输出超过 12K 时，工具结果保留完整 stdout/stderr，摘要不出现“输出已截断”。（验证：执行产生 60K 字符输出的成功和失败命令，检查内容与退出状态。）

## 资源保护不回归

- [x] 大于 1MiB 的文件仍被读取工具拒绝；二进制、非 UTF-8、工作区外路径仍返回对应失败结果。（验证：运行工具测试中的边界场景。）
- [x] 文件查找和代码搜索达到 200 条后仍停止收集并显示数量限制，而非无限返回。（验证：构造超过 200 个路径或匹配，检查数量和摘要。）
- [x] 命令的 30 秒超时、用户取消、启动失败与非零退出码行为保持原样。（验证：运行命令工具的既有超时、取消和失败测试。）

## 上下文外置集成

- [x] 内置读取工具返回大于 50K、小于 1MiB 的完整结果后，下一次模型请求前将其外置到 `.yucode/context/`。（验证：驱动 Agent 完成读取后继续下一轮，检查缓存文件存在和上下文外置事件。）
- [x] 外置缓存文件逐字等于内置工具取得的完整结果；Provider 请求历史只保留路径、预览和重新读取提示，不含完整原文。（验证：比较缓存、原始文件和 Provider 记录的请求历史。）
- [x] 小于 50K 的完整内置结果不被错误外置，仍作为原文保留在下一轮历史。（验证：构造约 20K 字符文件并检查请求历史。）
- [x] 工具结果完整化不改变权限确认、工具成功/失败状态、错误码或普通流式回复。（验证：运行 Agent、工具和 TUI 回归测试。）
